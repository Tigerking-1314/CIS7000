---
name: my-ways
description: When and how to use my road trip server. Use when the user says they like a place, wants to plan or change a road trip, or asks about a trip they saved before.
---

User says they like a place → save it as a favorite, with their reason as the note.
User wants a trip from places they like → list favorites first, then build the trip from favorites so the notes stay.
Before changing a trip → list saved trips and use the exact name. Never guess a name; a wrong name makes a new trip.
A trip with the same name already exists → ask before replacing it.
Removing a stop or a favorite → confirm with the user first.
"What was my trip?" → load the saved trip. Never answer from memory.
After a change → show the trip once, in order. Don't repeat it every turn.
User is just chatting about a place, not saving or planning → stay silent, use no tool.
